# EH3D-DESIGN-VERIFIER: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Automatic fixes proposed to the designer | A mechanism for a reviewable difference does not exist yet | the first reports are used |
| Power-electronics rule sets (current capacity, clearance and creepage) | They belong to the rule engine of the board tool first | that engine exists |
| A signed review document | Signing needs a key policy that nobody has decided, and no key is ever stored in a repository | a person signs the first review |
| The review in languages other than English | The words of the document are written once; the translations need the final wording | the wording of the review is settled |
| A task kind for the server | The server has no kind of task for a verification yet | the server accepts tasks from the engines |
| A comparison with a manufacturing profile | It needs the profile format and its limits, which are not accepted yet | the profile format is accepted |
